### 📋 Reservation Manager (Web App)

This is a simple web application that allows users to manage reservations directly in the browser. It is built using **HTML, CSS, and JavaScript** with no external libraries.

The application lets users:

* ➕ Add new reservations with a title, date, and description
* ✏️ Modify existing reservations
* 🗑️ Delete reservations
* 💾 Save data locally using browser storage

All reservations are displayed dynamically in a table, which updates instantly when changes are made.

The app uses **localStorage** to store data, meaning:

* Data is saved even after refreshing the page
* No backend or database is required

It also includes:

* A modern UI with popups for adding and editing data
* Interactive buttons for managing each reservation
* Responsive design for better viewing on different screen sizes

---

### 🧠 Technical overview

* **DOM manipulation** to create and update table content dynamically
* **Event delegation** to handle button clicks (edit/delete)
* **localStorage API** for persistent data storage
* **JavaScript objects & arrays** to manage reservations

This project demonstrates core frontend skills:

* Working with the DOM
